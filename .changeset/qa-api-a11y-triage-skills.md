Three skills join the agent layer: `qa-api` (compare the OpenAPI contract with the application, set up API authentication, run the API specs), `qa-accessibility` (run the accessibility specs or scan named pages and explain the findings) and `qa-triage` (sort the failures of a run and draft the product bugs through the triage spoke). A single approved case run live is still `qa-execute`.
